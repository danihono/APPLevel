# Graduation celebration images

Place optional promotion artwork in this folder using the transition slug:

- `white-to-blue.webp`
- `blue-to-purple.webp`
- `purple-to-brown.webp`
- `brown-to-black.webp`
- `white-to-gray-white.webp`
- `gray-white-to-gray.webp`
- `gray-to-gray-black.webp`
- `gray-black-to-yellow-white.webp`
- `yellow-white-to-yellow.webp`
- `yellow-to-yellow-black.webp`
- `yellow-black-to-orange-white.webp`
- `orange-white-to-orange.webp`
- `orange-to-orange-black.webp`
- `orange-black-to-green-white.webp`
- `green-white-to-green.webp`
- `green-to-green-black.webp`

`.webp` is tried first, then `.png`. If no file exists, the app shows the built-in belt fallback.
